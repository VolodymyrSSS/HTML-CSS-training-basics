CSS way for masonry layout implementation

This is just a quick copy/pasta 🍝 cheatsheet post with common use cases for the
new layout mode. Be aware of the browser support and embrace the progressive enhancement
as it works well with it.
But The Masonry has limited availability!

If yourbrowser doesn’t support display: grid-lanes yet: use one of the supported
engines (Safari 26.4 has a good support).

Columns and rows

The new display mode supports columns and rows. Perfecto! We use good old
grid-template-columns and grid-template-rows to define them. Like so:

Make a grid with 3 columns of equal width:

.grid{
   display: grid-lanes;
   grid-template-columns: repeat(3, 1fr);

   div {
     block-size: random(2lh, 10lh);
   }
}

Variable grid items size

If you want to resize one of the items, you can do so by using all
you already know. Here is an example.

Make a grid with columns where first item spans 2 units:

.grid{
   display: grid-lanes;
   grid-template-columns: repeat(3, 1fr);

   div {      block-size: random(2lh, 10lh);

     &:first-of-type {
       grid-column: span 2;
     }
   }
}

Tolerance

Browser tasked to draw masonry layout, iterates over the elements,
checks which column/row has the most empty room and places the next
item there. In some circumstances, this algorithm produces an unintuitive
results, namely it might be visually a little confusing and for assistive
tech users messed up a little. Here is where the flow-tolerance comes in.
The calculation to determine the next available column/row is adjusted by
the value of this property. The default value of flow-tolerance is 1em. So,
look at this example:

.grid{
   display: grid-lanes;
   grid-template-columns: repeat(3, 1fr);
   flow-tolerance: 1lh;

   div {
     padding: 0.5lh;
     border: 1px solid currentColor;

     &:nth-of-type(1) {
       block-size: 3lh;
     }

     &:nth-of-type(2) {
       block-size: calc(3lh - 1em - 1px);
     }

     &:nth-of-type(3) {
       block-size: 1lh;
     }

     &:nth-of-type(3) {
       block-size: 6lh;
     }
   }
}
